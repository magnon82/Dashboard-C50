# Business Management Suite · Carranza 50

Sistema integral de gestión empresarial (ERP operativo) para **Cluster Culinario · Carranza 50**: tablero de negocio, Master Control y módulos de operación (ventas, finanzas, eventos, RR.HH., staff, socios, etc.).

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js · Supabase · Vercel · GitHub Actions (sync Gmail / saldos)
